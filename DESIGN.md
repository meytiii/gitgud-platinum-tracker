# Design System: GitGud Soulsborne Assistant & Platinum Tracker

## Overview

**Creative North Star: "The Cartographer's Wayfinding Codex"**

GitGud embodies the feel of an ancient, weathered explorer's field logbook and scriptorium. Every questline milestone, boss defeat, and trophy requirement reads as a stamped waypoint on an unbroken expedition rail. It rejects generic gaming dashboard aesthetics (sterile spreadsheets, neon linear gradients, floating glass halos) in favor of deep charred slate, aged vellum surfaces, glowing amber hairlines, and iron-gall ink stamps.

The system delivers high information density without visual clutter, prioritizing instantaneous scanability and effortless single-tap interactions for players who are actively engaged in demanding Soulsborne combat across PC, console, or Steam Deck.

**Key Characteristics:**
- **Atmospheric Dark Fantasy Palette:** Deep obsidian foundation (`#0c0b0a`) accented by weathered brass/amber (`#d4a359`), aged vellum text (`#f0eae1`), and ember lockout alerts (`#c0392b`).
- **Harmonious Dual-Font Typography:** Majestically carved serif titles (`Cinzel`) paired with ultra-legible modern grotesk body copy (`Outfit`) and tabular digits (`JetBrains Mono`).
- **Tactile Waypoint Checkboxes:** Stamped diamond checkmarks that pulse with subtle amber resonance upon completion.
- **Unbroken Vertical Wayfinding Rails:** Clear visual progression spines linking chapters, objectives, and point-of-no-return lockout triggers.

## Colors

The palette is defined by high-contrast dark slate depths illuminated by incandescent gold and bonfire ember accents.

### Primary
- **Grace Gold** (`#d4a359`): Primary interactive accent, progress bar shimmer, active tab glows, and trophy completion milestones.
- **Radiant Amber** (`#f3c47a`): Hover state for interactive primary buttons and focus highlights.

### Secondary
- **Ember Lockout Red** (`#c0392b`): Dedicated high-visibility alert wash for missable NPC quests, fail states, and irreversible lockout triggers.
- **Shinobi Crimson Hover** (`#e74c3c`): Active hover state for danger tags and reset triggers.

### Neutral
- **Charred Obsidian Base** (`#0c0b0a`): Global application background ground.
- **Dark Vellum Panel** (`#161412`): Card surfaces and sidebar background.
- **Solid Scriptorium Slate** (`#1c1916`): Form controls, input backgrounds, and modal bodies.
- **Bone White** (`#f0eae1`): Primary body text ensuring ≥7:1 contrast ratio.
- **Illuminated Heading** (`#fdfbf7`): Pure bright heading text with subtle text shadow.
- **Pure White** (`#ffffff`): High-emphasis hero headlines and contrast badges.
- **Weathered Ink Muted** (`#8a7e72`): Secondary metadata, captions, and tooltips.

### Named Rules
**The One Resonance Rule.** The primary gold accent is applied strictly to interactive controls, progress gauges, and active navigation states. Information text remains crisp bone white or weathered ink.
**The Absolute Lockout Contrast Rule.** Missable items and quest lockouts always carry a dedicated crimson wash (`#c0392b`) with 1px border and distinct icon tag, ensuring zero ambiguous quest warnings.

## Typography

**Display Font:** `Cinzel` (with `Georgia, serif` fallback)
**Body Font:** `Outfit` (with `-apple-system, BlinkMacSystemFont, sans-serif` fallback)
**Tabular/Stat Font:** `JetBrains Mono` (with `monospace` fallback)

**Character:** A dignified fusion of ancient gothic epigraphy and clean contemporary digital legibility.

### Hierarchy
- **Display XL** (Weight: 900, Size: `2.5rem`, Line-Height: 1.15, Spacing: 0.06em): Hero banner titles and major landmark headers.
- **Display Hero** (Weight: 900, Size: `2.4rem`, Line-Height: 1.15, Spacing: 0.06em): Main page titles.
- **Headline** (Weight: 800, Size: `1.4rem`, Line-Height: 1.25, Spacing: 0.04em): Section titles, game header banners, and modal headings.
- **Title** (Weight: 800, Size: `1.15rem`, Line-Height: 1.3): Chapter titles, category card headers, and feature names.
- **Body** (Weight: 400, Size: `0.95rem`, Line-Height: 1.6): Standard quest instructions, item descriptions, and feature copy (measure 65–75ch).
- **Label** (Weight: 700, Size: `0.78rem`, Letter-Spacing: 0.08em, Uppercase): Stat badges, filter chips, button labels, and quick jump pills.

### Named Rules
**The Tabular Precision Rule.** All level stats, weights, roll percentages, and numeric checklist counters use `JetBrains Mono` with tabular numerals (`tnum: 1`) to eliminate layout jitter during active calculation.

## Layout

Layout is organized as a persistent sticky top bar with responsive drawer navigation and a centered wide-aspect canvas.

- **App Navigation Bar:** Fixed sticky 72px bar with logo, modes, active game picker dropdown, profile manager, and theme switcher.
- **Main Canvas:** Full-height scroll container with generous `32px 28px` breathing room on desktop and `20px 14px` padding on mobile.
- **Elastic Gallery & Bento Grids:** Elastic accordion flex layouts and auto-fitting CSS grids ensuring flawless presentation across widescreen monitors, tablets, and handheld devices.

## Elevation & Depth

Depth is established through rich tonal layering, charred slate surface borders, and subtle amber illumination rather than aggressive drop shadows.

### Shadow Vocabulary
- **Subtle Surface** (`box-shadow: 0 2px 8px rgba(0, 0, 0, 0.4)`): Base cards, checklist items, and profile select boxes.
- **Elevated Panel** (`box-shadow: 0 4px 16px rgba(0, 0, 0, 0.6)`): Accordion cards, planner decks, and quick jump panels.
- **Modal Depth** (`box-shadow: 0 16px 48px rgba(0, 0, 0, 0.95), 0 0 30px rgba(0, 0, 0, 0.9)`): Floating modal dialogues.
- **Gold Resonance Glow** (`box-shadow: 0 0 14px rgba(212, 163, 89, 0.4)`): Active progress bars and primary action buttons.

## Shapes

Forms are crisp and architectural with subtly softened corners:
- **Micro Radius** (`2px-4px`): Sliders, pills, and small buttons.
- **Small Radius** (`6px`): Buttons, inputs, filter chips, and checkbox containers.
- **Medium Radius** (`10px`): Category cards, feature bento boxes, and quick jump panels.
- **Large Radius** (`16px`): Hero cards, elastic cards, and modal containers.
- **Full Radius** (`9999px`): Progress bars and status pills.

## Components

### Buttons
- **Shape:** Architectural corners (`6px` radius).
- **Primary:** Gradient gold (`#d4a359` to `#f3c47a`), dark ink text (`#12100d`), font weight 800, padding `12px 24px`.
- **Secondary:** Dark vellum surface (`rgba(22, 20, 18, 0.85)`), 1px border (`#d4a359` at 25%), hover lift `-2px`.

### Elastic Accordion Cards
- **Shape:** Softened container (`16px` radius).
- **Flex Behavior:** Active card expands to `flex: 4.2` with full brightness and detail reveal; inactive cards compress to `flex: 1` with vertical title alignment.

### Canvas2D ASCII-Art Sprite
- **Engine:** Real-time quantized Canvas2D raster rendering with pulse animation, vignette, and bloom post-effects.

## Do's and Don'ts

### Do:
- **Do** maintain a strict 4.5:1 minimum contrast ratio for all secondary and muted descriptive copy.
- **Do** preserve 100% offline functionality and local persistence across all profiles and character builds.
- **Do** theme all browser surfaces (scrollbars, text selection, caret) from the design tokens.
- **Do** provide immediate haptic and visual confirmation on checklist toggles.

### Don't:
- **Don't** use generic unstyled browser checkboxes or default system sans-serif fonts.
- **Don't** add arbitrary neon gradients, zero-offset blur halos, or noisy background textures that impair readability.
- **Don't** use asymmetrical thick side-tab borders on checklist cards.
